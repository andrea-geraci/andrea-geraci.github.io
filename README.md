# andrea-geraci.github.io

Academic website with publications loaded from a BibTeX source.

## Update publications

1. Edit [publications.bib](publications.bib)
2. Add or modify BibTeX entries
3. Commit and push changes

The page [index.html](index.html) automatically reads [publications.bib](publications.bib)
through [publications.js](publications.js) and updates the Research and Publications
sections.
